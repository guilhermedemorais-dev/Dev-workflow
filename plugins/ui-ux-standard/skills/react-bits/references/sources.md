The official shadcn namespace is `@react-bits`; its URL template is
`https://reactbits.dev/r/{name}.json`. Use the exact item name from the current
component's official installation page, not a guessed slug or fixed dependency
list. Public registry/doc pages may evolve after the pinned source revision.

Inspect project components.json before proposing a registry entry. Use its
existing package manager and project-local CLI; no OS-specific shell snippets,
home-directory assumptions or global MCP modification are required here.
Read source/license before adoption and record the actually observed version.
Pro resources, accounts, billing and bulk collection installation are outside
this adapter. No component implementation is distributed with these references.
